# Brand logos

Drop one file per brand here, named by its code in lower case. It appears on the brand's tile
automatically, with no code change:

    lady_care.png   sonari.svg   juliet.webp   sukanya.png   libra.png   zola.png   groverson.png
    bodycare.png    floret.png   bonjour.png   ramraj.png    v_star.png  blossom.png

- PNG with a transparent background, SVG or WebP. About 240 × 120 px is plenty; keep each under 50 KB.
- A brand without a file keeps its coloured name, so logos can arrive one at a time.
- A brand added later in the admin gets a logo the same way: its code in lower case.
